# 手相 & 面相速查参考库

> 依据：《麻衣神相》《柳庄相法》《手相学》（中西合璧）

## 一、手相速查

### 手型判断

| 手型 | 特征 | 性格倾向 |
|---|---|---|
| 方形手 | 掌方、指方、指节明显 | 务实、踏实、执行力强，适合实业 |
| 圆锥形手 | 掌略圆、指尖细 | 感性、直觉强、艺术气质 |
| 长指手 | 手指细长、掌窄 | 思维敏锐、完美主义，适合文职/学术 |
| 宽掌短指 | 掌宽厚、指短 | 行动派、直接、体力好，适合实操类工作 |
| 软手 | 手感柔软，弹性大 | 享乐、依赖性强，但适应力好 |
| 硬手 | 手感硬实 | 固执、自律、意志力强 |

### 主线详解

#### 生命线

| 特征 | 解读 |
|---|---|
| 弧度大、包围金星丘 | 活力充沛，体质好，人生积极主动 |
| 弧度小、贴近拇指 | 活力偏弱，体质一般，行事保守 |
| 线长且清晰到底 | 寿元较长，晚年有靠 |
| 中途断裂 | 断裂处年龄段有重大变故（疾病/意外/转折） |
| 断后有平行副线（保护线） | 虽有波折但能化险为夷 |
| 末端分叉 | 晚年可能异地定居或生活模式大变 |
| 岛纹（椭圆形断纹） | 该年龄段身体状况差或有重大压力 |
| 线上有星纹 | 有突发状况，需注意健康 |

#### 智慧线（头脑线）

| 特征 | 解读 |
|---|---|
| 起点与生命线共起 | 谨慎、思虑周全，决策慢但稳 |
| 起点独立，不接生命线 | 独立、自主性强，决策快，偶有冲动 |
| 线长（延伸到小指下方） | 思维广博，适合策划、研究、艺术 |
| 线短（止于中指下方） | 专注实务，不好空想，执行力强 |
| 向下弯（弓形） | 想象力丰富，直觉强，感性 |
| 平直 | 理性、逻辑强，适合理工/商业 |
| 末端分叉 | 双重思维，两头都能顾，也容易想太多 |
| 岛纹 | 该年龄段精神压力大或有头部问题 |

#### 感情线

| 特征 | 解读 |
|---|---|
| 起点在食指下 | 感情理想化，对伴侣要求高 |
| 起点在中指下 | 感情务实，重稳定，容易付出 |
| 起点在无名指与中指之间 | 感情平衡，理想与现实兼顾 |
| 线长且清晰 | 感情专一，感情运较好 |
| 末端上翘（弯向食指） | 感情积极主动，追求浪漫 |
| 末端平直或下弯 | 感情偏理性，或有失落感 |
| 末端分叉 | 感情经历复杂，或有两段以上感情 |
| 线上有岛纹 | 该时期感情有波折、背叛或分离 |
| 断裂 | 感情出现较大变化或分手 |
| 多条平行感情线 | 桃花旺，感情经历多 |

#### 命运线（并非人人都有）

| 特征 | 解读 |
|---|---|
| 从手腕直通中指，清晰深刻 | 命运轨迹清晰，事业目标明确，贵人运好 |
| 线短或不明显 | 靠自己打拼为主，早期较辛苦 |
| 从生命线内部起 | 依靠家族/父母资源起步 |
| 从月丘（手腕小拇指侧）起 | 靠外部机遇、大众支持起家，适合公众行业 |
| 中途断裂后重新出现 | 事业经历重大转折，但能重振 |
| 多条命运线 | 多线发展，多才多艺，但容易分散精力 |
| 末端分叉 | 晚年有多种发展方向 |

### 副线速查

| 副线名称 | 位置 | 有此线代表 |
|---|---|---|
| 太阳线（成就线） | 无名指正下方，竖线 | 有名气、有成就感，财运与社会认可度高 |
| 健康线 | 小拇指下方，斜线 | 有此线者需注意身体；线清晰反而代表健康意识强 |
| 婚姻线 | 小拇指下方，横线 | 线数代表重要感情次数，深长者感情稳定 |
| 财运线（水星线） | 小拇指根部，竖线 | 商业头脑好，财运较佳 |
| 直觉线 | 月丘上弧线 | 第六感强，适合玄学、心理、医疗行业 |
| 旅行线 | 生命线末端外侧，横线 | 常有出行或异地生活机会 |

## 二、面相速查

### 三停

| 部位 | 位置 | 主管 | 好相 | 差相 |
|---|---|---|---|---|
| 上停 | 额头（发际→眉） | 少年运（0～30岁）、父母、贵人 | 宽阔饱满圆润 | 低窄、多皱纹、斜凸 |
| 中停 | 鼻梁（眉→鼻尖） | 中年运（30～50岁）、事业、财运 | 挺直圆润、山根高 | 鼻梁歪斜、鼻尖下勾 |
| 下停 | 下巴（鼻尖→下巴） | 晚年运（50岁后）、部下、子女 | 丰满圆润、下巴有肉 | 尖削、歪斜 |

三停均衡者，一生运势平稳，无大起大落。

### 五官详解

#### 额头

| 特征 | 解读 |
|---|---|
| 宽阔饱满、圆润光洁 | 贵气、聪明、贵人多、父母有助力 |
| 额头高挑（发际线靠后） | 少年运顺，早慧，思维广博 |
| 额头低窄（发际线靠前） | 少年运略苦，靠后天努力 |
| 额头多横纹（早年） | 少年经历坎坷，多操心 |
| 天庭（额头正中）饱满 | 官运、事业运好 |
| 额头左右不对称 | 早年家庭环境有起伏 |

#### 眉毛

| 特征 | 解读 |
|---|---|
| 浓密清秀、眉色黑亮 | 兄弟运好，贵人多，精力旺盛 |
| 眉毛稀疏、颜色淡 | 兄弟缘薄，贵人少，体力偏弱 |
| 眉头皱纹（川字纹） | 多思虑，压力大，早年较辛苦 |
| 眉毛散乱 | 做事不专一，人际关系多波折 |
| 剑眉（刚直） | 性格刚强，决断力好，但易冲动 |
| 柳叶眉（弯细） | 温柔、感性、桃花旺 |
| 眉尾下垂（八字眉） | 情绪化，重感情，为情所困 |
| 眉尾上扬 | 个性强，不服输 |

#### 眼睛（命宫，最重要）

| 特征 | 解读 |
|---|---|
| 眼神清澈有神 | 聪明、命运好，运势上扬 |
| 眼神浑浊、无神 | 精力差，近期运势低迷 |
| 丹凤眼（细长上扬） | 聪明、桃花旺，多情，事业有成 |
| 杏仁眼（圆润） | 温和、善良，人缘好 |
| 三白眼（黑眼珠偏上/偏下） | 性格极端，命运多波折 |
| 眼白多（四白眼） | 感情易出问题，做事冲动 |
| 卧蚕（下眼睑隆起） | 桃花旺，异性缘好，感情运佳 |
| 泪堂（卧蚕下方）有纹 | 感情有暗伤或失去至亲 |
| 眼角细纹多 | 操心多，或笑纹（性格开朗） |
| 眼袋重 | 肾气不足，婚姻宫有压力 |

#### 鼻子（财库）

| 特征 | 解读 |
|---|---|
| 鼻梁挺直、鼻头圆润饱满 | 财运好，正财稳定，中年运顺 |
| 山根（两眼间）高挺 | 贵人运强，中年事业有助力 |
| 山根低陷 | 中年多波折，需自己打拼 |
| 鼻头下勾（鹰钩鼻） | 精打细算，聚财能力强，但偏吝啬 |
| 鼻翼宽大 | 财库大，能聚财 |
| 鼻翼窄小 | 财来财去，不易积累 |
| 鼻梁有横纹 | 中年有阻碍，需防小人 |
| 鼻尖有痣 | 财运受阻，或健康信号 |

#### 嘴巴（福德宫）

| 特征 | 解读 |
|---|---|
| 嘴角上扬 | 乐观有福，晚年有享受 |
| 嘴角下垂 | 劳碌命，偏悲观，晚年要注意心态 |
| 嘴唇饱满红润 | 口福好，福气旺 |
| 嘴唇薄 | 理性，但情薄，伴侣缘较弱 |
| 人中（鼻到嘴间沟）深长 | 寿元好，子女运佳 |
| 人中浅短 | 子女缘薄或晚育 |
| 法令纹（嘴两侧竖纹，中年出现） | 中年后权力运、领导力增强；过深则孤独感强 |

#### 下巴（晚年运）

| 特征 | 解读 |
|---|---|
| 圆润饱满、有肉 | 晚年有靠，部下运好，子女孝顺 |
| 尖削 | 晚运孤独，部下缘薄 |
| 下巴宽（地阁方圆） | 晚年事业稳，财富积累好 |
| 下巴向前突出 | 个性固执，但意志力强 |
| 下巴后缩 | 优柔寡断，晚年较被动 |
